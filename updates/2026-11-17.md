# CazCad development update for November 17, 2026

**Windows.** The Extrude Join preview fix passed 115 focused tests. The first full Windows run passed 8,768 windowless and 3,669 interface tests. One two-sided Extrude control comparison failed. The merge is on hold while the team checks both interface styles with the same operation selected.

**Tools.** The main development branch now implements 296 of 439 registered commands. Rule Fillet, Pattern on Path, Rib, Web and solid Boundary Fill are in integration testing. Seven Inspect analyses are also under review.

**Linux.** CazCad opened a four-solid assembly in Ubuntu 24.04 under WSL2 with Mesa software rendering. All four solids survived a native save, reopen and STEP export. The application also installed in a fresh Python environment under an ordinary Linux user account, opened a design and passed all 19 startup checks.

**Sketching and drawings.** In the integration build, Create Sketch starts on a preselected flat face or plane. With no selection, you pick directly in the canvas. Drawing Properties now offers Basic, Standard and Detailed automatic dimensions. These changes are in testing.
