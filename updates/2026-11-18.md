# CazCad development update for November 18, 2026

The fix for the Extrude Join preview crash on textured parts passed independent review and landed on the main development branch at `994d1daa`. The two-sided Extrude check that held up yesterday’s merge passed on this build.

**Windows.** On that exact build, 4,012 interface tests and 9,228 windowless tests passed. The suite recorded 41 skips and 11 expected failures, with zero unexpected failures.

**Tools.** The command registry on that build lists 313 implemented commands out of 441, with 128 planned. Create Sketch now uses a preselected flat face. When you start without a selection, you can pick an origin plane directly on the canvas.

**Linux.** On Ubuntu 24.04 under WSL2, all 78 focused tests passed. The portable build also passed 19 startup checks after it was moved to a fresh folder, and it opened, saved and reopened a design.

**Next.** Work continues on keeping drawing revisions stable when another part in an assembly changes. That follow-up is in Windows testing, including checks for keyboard navigation in the application menu.
