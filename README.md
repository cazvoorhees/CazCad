# CazCad

CazCad is a local desktop CAD application for designing parts and making engineering drawings. A design can start with a constrained sketch, grow through a history of solid features, and be exported as STEP or documented on a dimensioned sheet.

## Development status

This repository is the public home for project updates. The application source is planned for a future open-source release.

[Read the development updates](./updates) or [view published announcements](https://github.com/cazvoorhees/CazCad/releases). To receive an announcement through GitHub, choose **Watch → Custom → Releases**. An [Atom feed](https://github.com/cazvoorhees/CazCad/releases.atom) is also available.

## Publishing an update

Add a Markdown file named `updates/YYYY-MM-DD.md` and push it to `main`. GitHub Actions publishes the dated note as a development announcement. Editing that file updates the existing announcement.
